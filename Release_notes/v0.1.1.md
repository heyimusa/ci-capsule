# v0.1.1

## Maintenance and reporting surfaces

`v0.1.1` does not change evidence collection, sanitization, replay-candidate
analysis, or command execution behavior. It improves the project's maintenance
and reporting surfaces:

- adds a public security reporting policy and contribution guidance;
- adds a dedicated form for redaction and false-assurance concerns;
- updates the threat-model reporting guidance for the public repository;
- updates the draft-release SBOM metadata to omit an invalid UUID-form serial number; and
- documents release-asset verification and expected `audit` behavior for
  synthetic credential-shaped fixture sentinels.

## What did not change

`ci-capsule` remains a Linux, owner-operated, read-only CLI. It does not execute
recovered commands, run or mutate workflows, download artifacts/caches, upload
bundles, or claim that a sanitized bundle is secret-free.

## Release assets

- `ci-capsule_v0.1.1_linux_amd64.tar.gz`
- `ci-capsule_v0.1.1_checksums.txt`
- `ci-capsule_v0.1.1_sbom.cdx.json`, a minimal CycloneDX 1.5 SBOM

Verify both checksummed assets after download:

```sh
sha256sum -c ci-capsule_v0.1.1_checksums.txt
```
